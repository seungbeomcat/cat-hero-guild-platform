# Cat Hero Guild Platform V4.1.6

Build date: 2026-10-16

멀티길드용 Cat Hero Guild Platform 전체 패키지입니다.

## V4.1.6 핵심 변경
- 메인 운영 메뉴를 5개로 조정하고 세 번째 위치에 `행운룰렛`을 추가했습니다.
- 길드원 누구나 행운 룰렛을 사용할 수 있으며 별도 관리자 인증이 필요하지 않습니다.
- 참여 인원 2~16명 선택 → 길드원 선택 → 추첨 항목 수 선택 → 항목명 직접 입력 순서로 진행합니다.
- `룰렛 시작`을 한 번 누르면 중복 당첨 없이 모든 항목을 자동 순차 추첨한 뒤 최종 결과를 한 번에 표시합니다.
- 추첨은 `crypto.getRandomValues()`를 사용하고 애니메이션과 결과 계산을 분리했습니다.
- 룰렛 사용기록은 Firestore/관리자 활동기록/로컬 기록에 저장하지 않습니다.
- 최종 결과에서 `단톡방 결과 이미지` 버튼으로 1080×1350 PNG를 만들고 공유 또는 저장할 수 있습니다.
- 룰렛 화면은 Royal Violet 테두리 계열을 유지하되 내부는 흰색이 아닌 어두운 우주/보라 배경과 강한 glow 연출을 사용합니다.

## 기존 기능 유지
- V4.1.5 OPS 차공 시작시간 기본값 저장 및 `rounds/null` 방어 로직 유지.
- V4.1.4 관리자 로그인 영구 유지.
- V4.1.1 중앙관리자 길드 완전삭제 및 잔여검증.
- 기존 계산기, 보스, 보상, 균열·은하 OPS 데이터 구조 유지.
- **은하 격전지 별도 개편안은 미반영 상태를 유지합니다.**

## 배포

현재 게시 중인 V4.1.1 계열 Rules를 그대로 두고 GitHub Pages 파일만 V4.1.6 전체 파일로 교체하면 됩니다.
