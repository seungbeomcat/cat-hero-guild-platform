# Cat Hero Guild Platform V4.0.6

V3.0 도살장 전용 기준본은 수정하지 않고, 별도 V4 멀티길드 플랫폼으로 운영하는 전체 패키지입니다.

## 핵심 구조
- 새 길드는 길드원 0명으로 시작합니다.
- 길드명·서버·길드원·격추·보스·OPS·보상 데이터는 `guildId` 단위로 분리합니다.
- 일반 길드원은 계산기 기능을 정상 사용하고, 나머지 운영 데이터는 조회·참고 용도로 이용합니다.
- 데이터 추가·수정·삭제는 해당 길드의 인증된 관리자만 가능합니다.
- 관리자 등록/로그인은 메인 화면의 `관리자` 메뉴에서만 시작합니다.
- 관리자 로그인은 같은 브라우저에서 직접 로그아웃할 때까지 유지하는 것을 원칙으로 합니다.

## 길드 전용주소
- 중앙관리자는 최초 관리자 설정용 임시 링크와 1회성 관리자 등록코드만 전달합니다.
- 실제 길드원 공유 주소는 길드관리자가 직접 생성하거나 안전한 키를 붙여넣어 설정합니다.
- 주소 비밀키 원문은 Firestore에 저장하지 않고 SHA-256 해시만 저장합니다.
- 길드관리자는 관리자 메뉴에서 언제든 전용주소를 변경할 수 있으며 변경 즉시 이전 주소는 폐기됩니다.

## 포함 화면
- `index.html` — 플랫폼 shell / 인증 / 길드 라우터
- `main.html` — 격전지 계산기 / 길드원 / 보상 / 관리자
- `boss.html` — 상층 2구역 보스 운영
- `ops.html` — 균열·은하 OPS

## 배포
GitHub Pages에 전체 파일을 업로드한 뒤 `firestore.multiguild.rules`를 Firebase Console에도 게시해야 V4.0.6 전용주소 기능이 정상 동작합니다.

자세한 변경사항은 `RELEASE_NOTES_V4.0.6.md`, 검증 범위는 `VALIDATION.md`를 확인하세요.
