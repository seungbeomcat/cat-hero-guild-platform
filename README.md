# Cat Hero Guild Platform V4.1.7

Build date: 2026-10-16

멀티길드용 Cat Hero Guild Platform 전체 패키지입니다.

## V4.1.7 핵심 변경
- 행운 룰렛 상단의 불필요한 소개/설명 카드를 제거했습니다.
- `길드원 공용` 배지를 모바일에서도 한 줄로 고정했습니다.
- iPhone/Safari에서 추첨 항목 입력 시 자동 클로즈업이 발생하지 않도록 입력 글자 크기를 16px 이상으로 보정했습니다.
- 룰렛 페이지의 헤더, 단계 카드, 선택 버튼, 선택 길드원, 입력창의 Royal Violet 글로우/유리광을 더 정돈했습니다.

## V4.1.6에서 이어지는 행운 룰렛 기능
- 메인 운영 메뉴는 `길드원 / 균열·은하 / 행운룰렛 / 보상분배 / 관리자` 5개이며 행운룰렛은 세 번째입니다.
- 관리자 외 일반 길드원도 사용할 수 있고 별도 관리자 인증이 필요하지 않습니다.
- 참여 인원 2~16명 → 길드원 선택 → 추첨 항목 수 → 항목명 직접 입력 순서입니다.
- 시작 한 번으로 모든 회차를 자동 순차 추첨하고 당첨자는 다음 회차에서 제외합니다.
- 추첨 결과는 `crypto.getRandomValues()` 기반으로 먼저 확정하고 룰렛 애니메이션은 그 결과를 표현합니다.
- 추첨 사용기록은 Firestore, 관리자 활동기록, localStorage/sessionStorage에 저장하지 않습니다.
- 최종 결과에서 `단톡방 결과 이미지` 버튼으로 1080×1350 PNG를 생성해 공유 또는 저장할 수 있습니다.

## 기존 기능 유지
- V4.1.5 OPS 자원 기본값 저장 및 `rounds/null` 방어 로직 유지.
- V4.1.4 관리자 로그인 영구 유지.
- V4.1.1 중앙관리자 길드 완전삭제 및 잔여검증.
- 기존 계산기, 보스, 보상, 균열·은하 OPS 데이터 구조 유지.
- **은하 격전지 별도 개편안은 미반영 상태를 유지합니다.**
