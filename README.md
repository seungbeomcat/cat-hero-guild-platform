# Cat Hero Guild Platform V4.1.0

Build date: 2026-10-15

멀티길드용 Cat Hero Guild Platform 전체 패키지입니다.

## V4.1.0 핵심 변경
- 메인 상단 길드 정보(`서버 | 길드명 | 인원수`)의 밝기를 우측 `격전지 계산기`와 통일했습니다.
- 좌/우 상단 텍스트에 왼쪽→오른쪽 shimmer 강조 효과를 추가했습니다.
- 움직임 감소 접근성 설정에서는 정적 밝은 텍스트로 표시됩니다.

## 기존 기능 유지
- V4.0.9 길드원 삭제 및 닉네임 변경 잔존키 수정.
- V4.0.8 길드원 추가·수정·삭제 UI 개선.
- V4.0.7 담당체력 한 줄 표시 및 OPS 최대 22:00.
- V4.0.6 관리자 로그인/관리, 길드 전용주소, 멀티길드 보안 구조.
