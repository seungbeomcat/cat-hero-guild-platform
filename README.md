# Cat Hero Guild Platform V4.2.2

Build date: 2026-10-16

## 이번 버전
- 행운 룰렛 결과 화면은 V4.1.13의 `시간/세션 → 전체 참여 명단 → 당첨 결과 → 이미지 공유 | 재추첨` 구조를 유지합니다.
- 시작/완료 시각 카드의 라벨·날짜·시간을 모두 가운데 정렬했습니다.
- 당첨 결과 카드를 더 밝은 퍼플·핑크·블루 그라데이션과 굵은 골드 테두리로 바꿔 당첨 영역의 시인성을 높였습니다.
- `이미지 공유`는 별도 축약 포스터가 아니라 현재 결과 화면과 같은 시각 구조를 세로형 고해상도 PNG로 렌더링합니다. 하단 `이미지 공유 / 재추첨` 버튼과 페이지 푸터는 공유 이미지에 포함하지 않습니다.
- 공유 payload에는 PNG 파일만 포함하며 텍스트 캡션을 보내지 않습니다.
- 당첨자가 1명일 때 결과 카드를 가운데 정렬합니다.
- 결과 제목 하단과 버튼 영역 상단에 얇은 구분선을 추가했습니다.
- `이미지 공유` / `재추첨` 버튼은 진한 남색 배경과 하늘색 테두리 스타일로 통일했습니다.
- V4.1.13에서 확정한 `추첨 결과` 제목, 추첨 ID/장문 설명 제거, 2열 2줄 당첨 카드, 동일 크기 액션 버튼은 그대로 유지합니다.

## 유지 사항
- 계산 결과 `이미지 바로 공유` / `보상 분배 룰렛`
- 길드 보상 신규 5종: `검은 보석`, `스타 펀치 장갑`, `스타 펀치 모자`, `스타 펀치 목도리`, `스타 펀치 신발`
- 룰렛 4×4 참여자 선택, 자동 순차 추첨, 중복 당첨 제외
- 계산기 참여자 일회성 룰렛 전달
- 길드 보상 `균열 / 은하 / 점령전 / 난투전 / 길드전` 5개 카테고리
- 룰렛 결과 Firestore/audit 미저장
- iOS/Safari 입력 자동 확대 방지
- 미완성 은하 격전지 개편안 미반영
- Firestore Rules 변경 없음
- V3 운영 퇴역 상태 유지
