# Cat Hero Guild Platform V4.1.2

Build date: 2026-10-15

멀티길드용 Cat Hero Guild Platform 전체 패키지입니다.

## V4.1.2 핵심 변경
- 메인 상단 `서버 | 길드명 | 인원수`와 `격전지 계산기`의 빛 이동을 더 선명하고 끊김 없는 좌→우 연속 애니메이션으로 조정했습니다.
- 관리자 카드의 `로그인 중` 텍스트를 제거하고 초록색 카드/방패 아이콘만 로그인 상태 표시로 유지합니다.
- 주간·월간 핵심 콘텐츠인 `균열·은하` 메뉴에 과하지 않은 테두리 순환 하이라이트를 추가했습니다.
- 길드원 추가·수정·삭제 폼의 테두리, 높이, 패딩, 카드 간격을 줄여 더 가볍고 정돈된 형태로 조정했습니다.
- 주요 팝업의 X 닫기 버튼을 더 크고 명확한 공통 스타일로 조정했습니다.
- OPS `회차 시작 설정`의 콘텐츠 선택기를 더 작고 가볍게 조정했습니다.
- 콘텐츠 명칭은 `균열의 격전지`는 그대로 유지하고 `은하의 격전지`를 `은하 격전지`로 바로잡았습니다.

## 기존 기능 유지
- V4.1.1 중앙관리자 길드 완전 삭제 및 연결 데이터 정리 기능.
- V4.0.9 길드원 삭제 및 닉네임 변경 잔존키 수정.
- V4.0.7 OPS 개인 최대 잔여시간 22:00.
- V4 데이터 이관 후 멀티길드 구조, 관리자 인증, 길드 전용주소, 보상·보스·OPS 데이터 구조.
