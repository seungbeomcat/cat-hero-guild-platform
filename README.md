# Cat Hero Guild Platform V4.1.11

Build date: 2026-10-16

## 이번 버전
- 계산 결과 상단 버튼을 더 얇고 선명한 독립 카드형으로 다듬고 `이미지 바로 공유` / `보상 분배 룰렛`으로 확정했습니다.
- `이미지 바로 공유`는 PNG 파일만 Web Share API로 전달하며 별도 `격전지 계산 결과` 텍스트를 함께 공유하지 않습니다.
- 계산 결과 공유 이미지는 실제 행 수에 맞춰 세로 길이를 줄이고, `이탈 기준` 파란 강조선을 고해상도에서 선명하게 다시 그립니다.
- 행운 룰렛 단톡방 이미지는 2번 시안 방향을 유지하면서 상단 두 제목의 폰트 크기를 맞추고 `최초 추첨 / 재추첨 N회차` 배지를 우측 상단으로 이동했습니다.
- 룰렛 공유 이미지의 회차 카드, 참여자 칩, 하단 메타 카드 높이/간격을 같은 계열끼리 통일했습니다.
- 길드 보상 선택 목록에 `검은 보석`, `스타 펀치 장갑`, `스타 펀치 모자`, `스타 펀치 목도리`, `스타 펀치 신발` 5종과 확정 아이콘을 추가했습니다.

## 유지
- 계산 결과 참여자를 `보상 분배 룰렛`으로 일회성 전달하고 참여자 선택 단계를 건너뛰는 V4.1.10 흐름 유지
- 행운 룰렛 4×4 참여자 선택, 자동 순차 추첨, 중복 당첨 제외 유지
- 룰렛 결과 Firestore/audit 미저장 유지
- 길드 보상 `균열 / 은하 / 점령전 / 난투전 / 길드전` 5개 카테고리 유지
- 미완성 은하 격전지 개편안 미반영
- Firestore Rules 변경 없음
- V3 운영 퇴역 상태 유지
