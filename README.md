# Cat Hero Guild Platform V4.1.8

Build date: 2026-10-16

## 이번 버전
- 행운 룰렛은 별도 인원수 선택 없이 길드원 16명을 4×4 그리드로 바로 표시합니다.
- 참여자를 2명 이상 직접 선택하고 `참여자 확인`을 누른 뒤 추첨 항목을 설정합니다.
- 자동 순차 추첨, 중복 당첨 제외, 최종 결과 일괄 출력, 1080×1350 단톡방 결과 이미지 기능을 유지합니다.
- 결과표와 공유 이미지에 시작/완료 시각, 추첨 ID, 현재 세션 기준 최초 실행/재추첨 회차를 표시합니다.
- 당첨 결과는 Firestore/관리자 활동기록에 저장하지 않습니다. 최초/재추첨 판별을 위한 구성 해시 회차 카운터만 sessionStorage에 임시 보관합니다.
- 길드 보상 분배 필터에 `길드전`을 추가해 5개 카테고리를 한 줄로 표시합니다. 길드전 보상 아이템 자체는 추후 추가합니다.

## 유지
- V4.1.5 OPS 자원 기본값/rounds null 방어 유지
- V4.1.4 관리자 로그인 영구 유지
- 미완성 은하 격전지 개편안 미반영
- Firestore Rules 변경 없음
