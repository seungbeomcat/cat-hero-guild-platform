# Cat Hero Guild Platform V4.1.1

Build date: 2026-10-15

멀티길드용 Cat Hero Guild Platform 전체 패키지입니다.

## V4.1.1 핵심 변경
- 중앙관리자 길드 카드의 버튼을 2열로 정리해 `관리자 설정 링크` 등 긴 문구가 한 줄로 표시됩니다.
- 중앙관리자 전용 `완전 삭제` 기능을 추가했습니다.
- 길드명 직접 입력 + 최종 확인을 거친 뒤 현재 V4 스키마의 길드 하위 데이터, 관리자, 활동기록, 초대코드, 전용주소 매핑을 정리하고 길드 기본 문서를 마지막에 삭제합니다.
- 삭제 직후 잔여 문서 자동검증을 수행하고, 완료 이력을 `platformAudit`에 남깁니다.

## 기존 기능 유지
- V4.1.0 메인 상단 길드 정보/제목 밝기 통일 및 좌→우 shimmer.
- V4.0.9 길드원 삭제 및 닉네임 변경 잔존키 수정.
- V4.0.8 길드원 추가·수정·삭제 UI 개선.
- V4.0.7 담당체력 한 줄 표시 및 OPS 최대 22:00.
- V4.0.6 관리자 로그인/관리, 길드 전용주소, 멀티길드 보안 구조.

## 배포 중요
V4.1.1은 **Firestore Rules 변경이 있습니다.**

1. `firestore.multiguild.rules` 전문을 Firebase Firestore Rules에 먼저 반영·게시합니다.
2. 그 다음 GitHub Pages 파일을 V4.1.1 전체 파일로 교체합니다.
3. 중앙관리자 화면에서 중복 테스트 길드를 삭제합니다.

기존 규칙을 그대로 둔 상태에서는 완전 삭제가 `permission-denied`로 중단될 수 있습니다.

자세한 변경사항은 `RELEASE_NOTES_V4.1.1.md`, 검증 범위는 `VALIDATION.md`를 확인하세요.
