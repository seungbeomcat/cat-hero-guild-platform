# Cat Hero Guild Platform V4.1.12

Build date: 2026-10-16

## 이번 버전
- 행운 룰렛의 최종 결과 화면을 결과 중심의 프리미엄 고가독성 구조로 전면 재설계했습니다.
- 추첨 종료 직후 결과 카드 중간이 아니라 `DRAW COMPLETE / 최종 추첨 결과` 시작 위치부터 정확히 보이도록 자동 스크롤을 보정했습니다.
- 회차 결과, 전체 참여 명단, 최초/재추첨 상태를 우선 배치하고 시작/완료 시각과 추첨 ID는 하단의 읽기 쉬운 검증 정보 영역으로 정리했습니다.
- 룰렛 단톡방 결과 이미지도 같은 디자인 원칙으로 다시 구성하고 메타 정보 글자를 확대했습니다.
- 룰렛 공유는 PNG 파일만 Web Share API에 전달하여 카카오톡에 별도 텍스트가 자동 첨부되지 않도록 했습니다.
- 길드 보상 분배의 수량 입력은 iPhone/Safari에서 숫자 키패드가 열려도 화면이 자동 확대되지 않도록 16px 모바일 입력 규칙을 적용했습니다.
- 320px급 구형 휴대폰부터 최신 대화면 휴대폰/태블릿까지 잘림과 가로 오버플로를 줄이도록 반응형 규칙을 보강했습니다.

## V4.1.11 기능 유지
- 계산 결과 `이미지 바로 공유` / `보상 분배 룰렛`
