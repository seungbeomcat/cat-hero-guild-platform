# Cat Hero Guild Platform V4.1.5

Build date: 2026-10-16

멀티길드용 Cat Hero Guild Platform 전체 패키지입니다.

## V4.1.5 핵심 변경
- 균열·은하 OPS에서 현재 회차가 없어도 길드원별 차공 시작 시간을 저장할 수 있습니다.
- 길드원별 시작 시간은 20:00~22:00 범위에서 관리하며, 다음 회차를 시작할 때 자동 반영됩니다.
- 회차 미진행 상태에서는 길드원 상세의 칼은 10/10으로 고정하고 시간만 다음 회차 기본값으로 저장합니다.
- 진행 중 회차에서 시간 한도를 20분보다 높게 확장한 경우 현재 회차와 향후 기본값을 함께 보존합니다.
- `round.id == null` 상태에서 Firestore `rounds/null` 저장을 시도하던 경로를 제거하고 저장 함수에도 방어 검증을 추가했습니다.

## 기존 기능 유지
- V4.1.4 관리자 로그인 영구 유지: 같은 브라우저에서는 명시적 로그아웃 전까지 인증 복원을 유지합니다.
- V4.1.1 중앙관리자 길드 완전삭제 및 삭제 후 잔여검증.
- V4.0.9 길드원 삭제 및 닉네임 변경 잔존키 수정.
- V4.0.7 OPS 개인 최대 잔여시간 22:00.
- V4.0.6 관리자 로그인/관리, 길드 전용주소, 멀티길드 보안 구조.
- 기존 균열·은하 회차/보스/과거기록 데이터 구조는 그대로 유지합니다.

## 배포
V4.1.5는 **Firestore Rules 변경이 없습니다.**

현재 게시 중인 V4.1.1 계열 Rules를 그대로 두고 GitHub Pages 파일만 V4.1.5 전체 파일로 교체하면 됩니다.
처음 차공 시작 시간을 저장하면 `guilds/{guildId}/data/opsResourceDefaults` 문서는 관리자 권한으로 자동 생성됩니다. 수동 문서 생성은 필요하지 않습니다.

자세한 변경사항은 `RELEASE_NOTES_V4.1.5.md`, 검증 범위는 `VALIDATION.md`를 확인하세요.
