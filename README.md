# Cat Hero Guild Platform V4.1.10

Build date: 2026-10-16

## 이번 버전
- 행운 룰렛은 별도 인원수 선택 없이 길드원 최대 16명을 4×4 그리드로 바로 표시합니다.
- 참여자를 2명 이상 직접 선택하고 `참여자 확인`을 누른 뒤 추첨 항목을 설정합니다.
- 자동 순차 추첨, 중복 당첨 제외, 최종 결과 일괄 출력 구조를 유지합니다.
- 룰렛 상단 포인터의 꼭짓점이 원판을 향하도록 방향을 바로잡았습니다.
- 결과 신뢰 정보 영역을 `최초 추첨 / 재추첨 N회차`, 시작·완료 시각, 추첨 ID로 다시 구성했습니다.
- 최종 결과 화면과 단톡방 결과 이미지 모두에 추첨 시작 당시 `전체 참여 명단`을 표시합니다. 당첨자는 금색으로 구분합니다.
- 단톡방 결과 이미지는 1080×1350을 유지하면서 제목, 상태, 결과, 참여 명단의 폰트와 정보 밀도를 크게 개선했습니다.
- 당첨 결과는 Firestore/관리자 활동기록에 저장하지 않습니다. 최초/재추첨 판별을 위한 구성 해시 회차 카운터만 sessionStorage에 임시 보관합니다.
- 길드 보상 분배 필터의 `길드전` 5번째 카테고리를 유지합니다. 길드전 보상 아이템 자체는 추후 추가합니다.
