# Cat Hero Guild Platform V4.0.8

빌드 날짜: 2026.10.15

V4.0 계열은 도살장 V3.0 전용 프로젝트와 분리된 멀티길드 플랫폼입니다. 각 길드는 같은 계산기·보스·균열/은하·보상분배 기능을 사용하지만 데이터와 관리자 권한은 길드 단위로 분리됩니다.

## V4.0.8 핵심 변경
- 관리자용 길드원 추가·수정·삭제 입력 화면을 전면 재디자인했습니다.
- 길드원 식별 / 기본 설정 / 지역 격추 / 상층 격추로 입력 구조를 그룹화했습니다.
- 숫자 오른쪽 정렬, `%` 단위 고정, Royal Violet 입력 디자인, 헤더 닫기 버튼 위치, 하단 저장/삭제 액션 영역을 개선했습니다.
- 작은 모바일과 대화면에서 동일한 정보 구조가 유지되도록 반응형 규칙을 보강했습니다.

## 유지 기능
- V4.0.6의 관리자 로그인/권한 및 길드 전용주소 구조
- V4.0.7의 담당체력 한 줄 표시
- 균열·은하 길드원 잔여시간 최대 22:00 보정
- 기존 계산식, 보스, 보상분배, 길드원 저장 데이터 구조

## Firebase
V4.0.8은 Firestore Rules 변경이 없습니다. V4.0.6 규칙을 이미 게시했다면 GitHub Pages의 전체 파일만 교체하면 됩니다. 새 Firebase 프로젝트에 배포하는 경우에만 패키지의 `firestore.multiguild.rules`를 게시합니다.

자세한 변경사항은 `RELEASE_NOTES_V4.0.8.md`, 검증 범위는 `VALIDATION.md`를 확인하세요.
