# Cat Hero Guild Platform V4.1.13

Build date: 2026-10-16

## 이번 버전
- 행운 룰렛 결과 화면을 `시간/세션 → 전체 참여 명단 → 당첨 결과 → 이미지 공유 | 재추첨` 순서로 재구성했습니다.
- 결과 제목은 `추첨 결과`로 단순화하고 모든 화면 폭에서 이전보다 작고 균형 있게 표시합니다.
- `추첨 ID`, `현재 브라우저 세션에서...`, `추첨 시작 당시 포함된 길드원` 등 장문 보조 문구를 제거했습니다.
- 당첨 결과의 `1차/2차/3차` 표기를 없애고, 각 카드에 `당첨 품목 / 당첨 길드원`을 동일 크기의 2줄 중앙 정렬로 표시합니다. 한 줄에는 최대 2개의 결과 카드를 배치합니다.
- 당첨 결과 카드 높이를 줄여 화면을 더 컴팩트하게 만들었습니다.
- `이미지 공유`와 `재추첨` 버튼은 동일 폭·동일 높이로 맞추고 좌우/중앙 여백을 균형 있게 유지합니다.
- `재추첨`은 현재 참여자와 추첨 항목 구성을 그대로 사용해 즉시 다시 추첨합니다.
- 기존 `단톡방 결과 이미지` 전용 미리보기/모달을 제거하고, 현재 결과 카드와 같은 정보 구조의 고해상도 PNG를 시스템 공유창으로 바로 보냅니다. 공유 payload에는 이미지 파일만 포함하며 별도 텍스트는 보내지 않습니다.

## 유지 사항
- 계산 결과 `이미지 바로 공유` / `보상 분배 룰렛`
- 길드 보상 신규 5종: `검은 보석`, `스타 펀치 장갑`, `스타 펀치 모자`, `스타 펀치 목도리`, `스타 펀치 신발`
- 룰렛 4×4 참여자 선택, 자동 순차 추첨, 중복 당첨 제외
- 계산기 참여자 일회성 룰렛 전달
- 길드 보상 `균열 / 은하 / 점령전 / 난투전 / 길드전` 5개 카테고리
- 룰렛 결과 Firestore/audit 미저장
- iOS/Safari 입력 자동 확대 방지
- 미완성 은하 격전지 개편안 미반영
- Firestore Rules 변경 없음
- V3 운영 퇴역 상태 유지
